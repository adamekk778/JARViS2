# JARVIS 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Windows voice+chat AI assistant with a macOS-style notch, full settings, agent tools ("superpowers"), and an Android companion app — shipped as a downloadable `JARVIS-Setup.exe` and `JARVIS.apk`.

**Architecture:** Python core (`core/jarvis`) runs agent, tools, voice, memory and a FastAPI/WebSocket server on :8765. One Vite+TS web UI (`web/`) serves the notch, the chat/settings dashboard and the mobile page; pywebview hosts notch + chat windows on PC, Capacitor wraps the mobile page into an APK. GitHub Actions builds the Windows installer (PyInstaller + Inno Setup) and the APK and publishes them to a GitHub Release.

**Tech Stack:** Python 3.11+, FastAPI, uvicorn, httpx, pydantic, tomllib/tomli-w, keyring, SQLite; pywebview, pystray, keyboard; sounddevice, openwakeword, faster-whisper, edge-tts, piper-tts; pycaw, psutil, pyautogui, mss, winsdk, yt-dlp, ddgs, trafilatura, pypdf, python-docx, openpyxl, python-pptx, rapidocr-onnxruntime, playwright, mcp; Vite + TypeScript, marked, highlight.js, qrcode; Capacitor 6.

**Spec:** `docs/superpowers/specs/2026-10-23-jarvis-design.md`

## Global Constraints

- Everything must run free: default brain chain `omniroute (http://localhost:20128/v1) → ollama (http://localhost:11434)`.
- Server port `8765`; WS endpoint `/ws?token=`; token required for any non-`127.0.0.1` client; `settings_set` only from localhost.
- Agent: max 8 LLM rounds per request; danger tools need `confirm_request` (30 s timeout → cancelled); computer use max 30 steps.
- Attachments: inline text ≤ 8000 chars, rest via `read_attachment`; max upload 200 MB.
- Context window: last 20 messages of the current conversation.
- TTS default `cs-CZ-AntoninNeural`, Piper fallback `cs_CZ-jirka-medium`; STT default faster-whisper `small`; wake word `hey_jarvis`; end of speech 0.8 s silence.
- Data dir `%APPDATA%\JARVIS` (Linux/test: `$JARVIS_HOME` or `~/.jarvis`): `config.toml`, `jarvis.db`, `files/`, `skills/`, `logs/`.
- Notch: idle ~200×32, expanded ~680×240, hover open delay 150 ms, close delay 400 ms, answer linger 6 s.
- Hotkeys: `ctrl+space` talk/type, `ctrl+shift+j` chat window.
- Every Windows-only import is lazy and guarded so the core imports and tests pass on Linux.
- UI language Czech; code/identifiers English.

## Review Focus

1. LLM endpoint returns 400 for `tools` (model without tool support) → retry without tools, remember per provider. Test in Task 2.
2. All providers down → assistant says it has no brain, no crash, `error` event emitted. Test in Task 5.
3. Upload without/with wrong token from non-localhost → 401; from localhost → ok. Test in Task 6.
4. Huge/binary/corrupt attachment (garbage PDF) → stored, extraction error captured, agent still answers. Test in Task 4.
5. Two clients connected → message from one appears on the other (`user_message` broadcast). Test in Task 6.

### Task 2: LLM providers and router

**Files:** Create `core/jarvis/llm/{__init__,base,openai_compat,ollama,router,presets}.py`; Test `core/tests/test_llm_router.py`

**Interfaces — Produces:**
- `base.Chunk` dataclass: `text: str = ""`, `tool_calls: list[ToolCall] | None`, `done: bool`; `ToolCall(id, name, arguments: dict)`.
- `base.LLMProvider` protocol: `id`, `model`, `async stream(messages: list[dict], tools: list[dict] | None) -> AsyncIterator[Chunk]`; raises `ProviderError(retryable: bool)`.
- `presets.PRESETS: dict[str, dict]` (omniroute, openrouter, groq, gemini, lmstudio, ollama, custom) with spec base URLs.
- `router.Router(cfg_brain, key_lookup)`: `async stream(messages, tools, need_vision=False) -> AsyncIterator[Chunk]`, `last_used -> (provider_id, model)`; fallback on network error / 429 / 5xx / first-token timeout 15 s; on 400 mentioning tools → retry same provider without tools and add id to `no_tools`.

- [ ] Tests with `httpx.MockTransport`: first provider 500 → second used; 429 → next; tools-400 → retried without `tools` and remembered; SSE tool_call deltas assembled into one `ToolCall`; all fail → `AllProvidersFailed`.
- [ ] Implement (OpenAI SSE parsing incl. streamed `tool_calls` index merging; Ollama `/api/chat` NDJSON), pass, commit.

**Interfaces — Produces:**
